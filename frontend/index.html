Cómo funciona

Tres pasos, un archivo listo para repartir en clase.

1. Elige categoría y dificultad

Filtra tu banco de preguntas por tema — matemáticas, historia, ciencia — y por nivel: fácil, media o difícil.

2. Genera con un clic

El sistema mezcla las opciones A, B, C y D en cada pregunta, así ningún examen sale igual dos veces.

3. Descarga ambos PDF

Recibes la hoja del alumno y la clave del maestro con las respuestas resaltadas en verde, listas para imprimir.

Ningún examen se repite

Cada vez que generas un examen, las preguntas se eligen al azar de tu banco y las opciones A–D se barajan de nuevo. Ideal para grupos numerosos o exámenes de recuperación.

Aguanta muchos maestros a la vez

Construido sobre FastAPI y Docker: varios profesores pueden generar exámenes al mismo tiempo sin que el sistema se congele ni se cruce la información de nadie.
